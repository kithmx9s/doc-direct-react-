# Doc Direct - Hospital Network System

Your Direct Path to Healthcare - A comprehensive hospital network management system connecting patients with healthcare providers across multiple hospitals.

## Features

- 🔍 Smart search by specialty, location, or doctor name
- 📅 Seamless appointment booking with real-time availability
- 📋 Centralized medical records with patient-controlled access
- 👥 Multi-role authentication (Patient/Doctor/Hospital/Admin)
- 📱 Fully responsive design
- ✨ Modern UI/UX with smooth animations

## Tech Stack

- **Frontend:** React 18
- **Routing:** React Router DOM
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Build Tool:** Vite

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/doc-direct.git
cd doc-direct
```

2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm run dev
```

4. Open http://localhost:5173 in your browser
